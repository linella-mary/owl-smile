# owl-smile-data

Общая база смайлов, иконок и эффектов ников для расширения **Owl Smile**.
Файлы меняет расширение (страница «Загрузка»), руками править не нужно.

| Путь | Что лежит |
|---|---|
| `meta.json` | версия формата |
| `emotes/<Код>.json` | смайл: код, картинка, автор |
| `badges/<id>.json` | иконка у ника |
| `paints/<id>.json` | эффект ника (пресет + цвета) |
| `users/twitch/<логин>.json`, `users/vk/<ник>.json` | какие иконки и эффект у зрителя |
| `img/<хеш>.webp` / `.gif` | картинки (имя — хеш содержимого) |

Откатить чужую правку — `git revert <коммит>` и push.
